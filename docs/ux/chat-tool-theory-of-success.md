# Chat Tool: Theory of Success

## Overview

This document describes the Chat tool's theory of success — the foundational goals, user outcomes, and design principles that define what success looks like for the Chat component in the taxonomy-editor.

## Goals

- **User Goal:** Enable conversational interaction with the taxonomy to explore claims, perspectives, and relationships through guided dialogue.
- **System Goal:** Provide a natural-language interface that maintains consistency with the underlying BDI debate framework while remaining intuitive for end users.
- **Outcome Goal:** Users develop deeper understanding of AI safety perspectives through multi-turn dialogue with the debate engine.

## Key Success Metrics

- **Engagement:** Users initiate chat interactions when exploring complex claims or POV disagreements.
- **Clarity:** Chat responses help users understand nuanced distinctions between safety perspectives.
- **Integration:** Chat findings surface in the main taxonomy interface (node detail, lineage, etc.).

## Design Principles

1. **Conversational Natural Language** — Users should be able to ask questions in their own words, not memorize syntax.
2. **Transparency to Debate Framework** — Chat responses should indicate which POV or agent they represent, maintaining visibility into the underlying debate structure.
3. **Exploration, Not Prescription** — Chat should help users discover connections and tradeoffs, not prescribe conclusions.

## User Scenarios

- Exploring what an accelerationist perspective would say about AI capabilities claims
- Understanding disagreements between safety perspectives on a specific policy action
- Asking follow-up questions to clarify a debate agent's position
