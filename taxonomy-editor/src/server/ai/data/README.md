# `ai/data/`

## `geoCountryIpv4.json`

An offline IPv4-to-country lookup table used by the free-pool geo restriction (t/4486, t/4410 item 2) to keep the server-provided free Gemini key pool out of the EEA, Switzerland and the UK, per Gemini's API terms. No third-party network lookup is made at request time — this file is generated ahead of time and bundled with the server.

**Source and licence:** [DB-IP](https://db-ip.com) — "Country Lite" database, downloaded from `download.db-ip.com/free/`.

**Generated by:** `ai/scripts/build-geo-db.mjs`. See that script's header for the build process (download, parse, merge adjacent same-country ranges, pack). Not checked for staleness at build time — the server itself WARNs (`ai/freePoolGeoGuard.ts`'s `warnIfStale`) when the bundled `sourceDate` is more than 60 days old. A monthly refresh job is tracked in t/4488.

**Scope:** IPv4 only (v1). An IPv6 client address is refused with its own reason code (`ipv6-unsupported`), distinct from an unresolvable address (`no-public-ip`) — see `ai/freePoolGeoGuard.ts`. Full IPv6 coverage is a follow-up, pending real-traffic evidence of the IPv6 client share (t/4486#4).
